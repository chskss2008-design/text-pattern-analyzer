
# Text Pattern Analyzer

A web-based Theory of Computation project that demonstrates Deterministic Finite Automata (DFA) and text analysis through an interactive interface.

## Features

- Accepts text input from users.
- Generates a concise extractive summary.
- Demonstrates DFA states and transitions.
- Displays step-by-step DFA simulation.
- Shows transition history and the final state.
- Provides a simple web interface built with Flask.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
